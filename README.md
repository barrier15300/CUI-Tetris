# CUI-Tetris

コマンドプロンプト上で遊べるテトリスです

C++20で記述していますが、内部ロジックはシンプルです

## 遊び方
管理者権限を与えて起動してください

こんな見知らぬソフトに管理者権限を与えるのが怖い場合は、
Windowsターミナルホストとして起動するのではなくWindowsコンソールホストとして起動してください

それすらめんどくさかったら使用するフォントを変えてください

それすらもめんどくさかったら、このリポジトリをクローンしてGUI向けに改造してください

## 操作方法
【移動】
「A」「D」

【回転】
「J」「L」

【ソフトドロップ】
「S」

【ハードドロップ】
「Space」

【ホールド切り替え】
「左Shift」

【ゲーム終了】
「Esc」
